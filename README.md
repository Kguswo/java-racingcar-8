# 자동차 경주
## 기능 요구사항
초간단 자동차 경주 게임을 구현한다.
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다.

### 입력
- 경주할 자동차 이름 (쉼표(`,`) 기준으로 구분, 각 이름은 5자 이하)
- 시도할 횟수

### 출력
- 각 라운드별 자동차 위치
- 최종 우승자

## 구현할 기능 목록

### 1. 입력 처리
- 자동차 이름 입력받기
    - 입력 메시지 출력: "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)"
- 시도 횟수 입력받기
    - 입력 메시지 출력: "시도할 횟수는 몇 회인가요?"

### 2. 입력값 파싱 및 검증
- 자동차 이름 문자열 파싱
    - 쉼표(`,`)를 기준으로 문자열 분리
- 잘못된 값 유효성 검증
    - 빈 이름이 있는지 확인
    - 각 이름이 5자 이하인지 확인
    - 중복된 이름이 있는지 확인
- 시도 횟수 유효성 검증
    - 숫자 형식인지 확인
    - 양수(1 이상)인지 확인

### 3. 게임 로직
- 자동차 생성
    - 이름을 가진 자동차 객체 생성
    - 초기 위치는 0으로 설정
- 무작위 값 생성
    - `pickNumberInRange(0, 9)` 사용
- 자동차 이동 조건 판단
    - 무작위 값이 4 이상이면 전진
    - 4 미만이면 정지
- 각 라운드 실행
    - 모든 자동차에 대해 무작위 값 생성 및 이동 처리
- 전체 게임 실행
    - 입력받은 횟수만큼 라운드 반복 실행

### 4. 우승자 결정
- 최대 이동 거리 계산
    - 모든 자동차 중 가장 많이 전진한 거리 찾기
- 우승자 찾기
    - 최대 이동 거리와 같은 위치에 있는 모든 자동차 찾기
- 우승자 이름 포맷팅
    - 우승자가 한 명인 경우: 이름만 출력
    - 우승자가 여러 명인 경우: 쉼표(`,`)와 공백으로 구분하여 출력

### 5. 출력
- 실행 결과 헤더 출력
    - "실행 결과" 메시지 출력
- 각 라운드 결과 출력
    - 자동차 이름과 이동 거리 출력
    - 형식: `{자동차이름} : {-를 이동거리만큼 반복}`
    - 각 라운드마다 빈 줄로 구분
- 최종 우승자 출력
    - 형식: `최종 우승자 : {우승자이름}`
    - 공동 우승자인 경우: `최종 우승자 : {이름1}, {이름2}`

### 6. 예외 처리
- 잘못된 자동차 이름 입력 시 예외 발생
    - 빈 이름이 포함된 경우
    - 5자를 초과하는 이름이 있는 경우
    - 중복된 이름이 있는 경우
    - `IllegalArgumentException` 발생 후 애플리케이션 종료
- 잘못된 시도 횟수 입력 시 예외 발생
    - 숫자가 아닌 값을 입력한 경우
    - 0 이하의 숫자를 입력한 경우
    - `IllegalArgumentException` 발생 후 애플리케이션 종료
